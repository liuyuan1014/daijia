# 工业园区UAV飞行任务调度平台

## 📋 项目简介

工业园区UAV飞行任务调度平台是一套完整的无人机任务管理系统，从原代驾平台演进而来。平台支持**运营商**发布无人机飞行任务，**飞手**接单并操控无人机完成飞行任务。该项目是**校招Java后端工程师**学习Spring Cloud微服务架构的最佳案例。

核心场景：
- 🏢 **运营商端**：创建飞行任务，管理无人机资源，查看实时飞行轨迹
- 👨‍✈️ **飞手端**：接收任务邀约，操控无人机执行任务，上传任务数据
- 📊 **管理后台**：系统监控，数据统计，风险评估，财务结算

**典型业务指标**：支撑1000+并发任务分配、99.9%支付成功率、95%任务分配准确率

## 🚀 核心技术亮点

### 1. 高并发任务分配（1000+并发）
**场景**：多个飞手同时接单，任务快速分配

**方案**：
- Redis高性能查询（5公里范围内飞手）
- Set结构防重复推送、List结构队列缓存
- 分布式锁确保一个任务只分配一个飞手
- 异步处理+消息队列削峰
- 三层缓存架构（Caffeine本地缓存+Redis+数据库）

**成果**：支撑1000+并发、平均响应时间200ms、99percentile<500ms

### 2. 微信支付完整流程
**场景**：用户支付→订单创建→任务执行

**方案**：
- 微信支付V3 API集成
- RSA签名验证防伪造
- 异步消息解耦支付与任务服务
- 幂等消费保证消息重复处理结果一致
- 四层消息保证机制（生产端confirm、RabbitMQ持久化、消费端手动确认、定期对账）

**成果**：99.9%支付成功率、完全的账款一致性

### 3. 分布式架构设计
**服务拆分**：
- 按业务域拆分10个微服务
- 微服务独立开发、部署、扩展
- Feign声明式调用+负载均衡
- 网关统一入口做路由、限流、鉴权

**服务治理**：
- Nacos配置中心动态管理
- 自动化服务发现与注册
- Hystrix熔断降级保护
- 支持灰度发布

### 4. 最终一致性保证
**方案**：
- 支付成功立即返回（快速响应）
- 异步消息通知任务服务
- 任务服务宕机时消息缓存在RabbitMQ
- 定期对账发现不一致并自动补偿
- 用户可接受秒级延迟

### 5. 缓存策略优化
**三层缓存**：
- L1：Caffeine本地缓存（10分钟TTL）- 热点飞手信息
- L2：Redis分布式缓存（1小时TTL）- 任务详情、用户信息
- L3：MySQL数据库

**Cache-Aside模式**：
- 读：缓存→数据库→回写
- 写：数据库→删除缓存
- 布隆过滤器解决缓存穿透

**性能提升**：API响应时间从500ms降到200ms

### 6. 任务分配智能化
**算法**：
- 地理位置推送（5公里范围）
- 简单高效（优于复杂加权算法）
- 飞手自主选择接单
- 95%任务分配准确率

**保障**：
- 定时任务重复分配
- 没人接单时扩大搜索范围
- 监控飞手接单率、工作均衡度

## 📊 核心业务流程

### 1. 任务发布与接单
```
运营商创建飞行任务（web-customer）
  ↓
任务进入service-task任务服务
  ↓
Drools规则引擎评估飞手匹配度和风险等级
  ↓
Redis搜索5公里范围内的飞手
  ↓
RabbitMQ异步推送任务给飞手列表
  ↓
飞手App收到邀约 → 接单/拒单（service-uav-pilot）
  ↓
分布式锁确保任务唯一分配
```

### 2. 飞行任务执行
```
飞手接单后获取任务详情
  ↓
获取实时地图数据（service-map）
  ↓
开始无人机飞行操控
  ↓
实时轨迹上报到service-task
  ↓
任务执行中的每个状态变更通过MQ异步传播
  ↓
任务完成 → 生成订单（service-order）
```

### 3. 支付与结算
```
任务完成 → service-order生成订单
  ↓
前端调用service-payment微信支付接口
  ↓
支付服务查询支付表检查重复请求
  ↓
调用微信支付V3 API获取预支付ID
  ↓
前端生成二维码，用户扫码支付
  ↓
微信回调我们的wxnotify接口
  ↓
验证RSA签名确认回调真实性
  ↓
查询支付表状态（幂等性检查）→ 状态变更→发送MQ消息
  ↓
task-service消费MQ消息，更新任务状态
  ↓
定期对账检查账款一致性（每晚）
```

## 🔐 系统设计亮点

### 并发控制
- **分布式锁**（Redis）：飞手接单唯一性
- **乐观锁**：数据库并发更新
- **Semaphore限流**：关键接口流量限制
- **令牌桶限流**（网关）：每秒1000请求

### 数据一致性
- **最终一致性**：支付→任务异步处理
- **Seata分布式事务**：强一致性需求
- **幂等消费**：消息重复处理的结果一致
- **定期对账**：发现不一致自动补偿

### 高可用设计
- **服务熔断降级**（Hystrix）：单点故障隔离
- **消息队列缓冲**：任务服务宕机时消息不丢失
- **多实例部署**：Feign自动转移请求到健康实例
- **缓存降级**：数据库故障时缓存仍可用

### 安全性
- Spring Security + JWT认证
- 微信支付RSA签名验证
- 接口访问权限控制
- 敏感数据加密存储
